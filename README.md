# PCA–ICA geometric equivalence

Reproducible Python code and **synthetic numerical data** accompanying the manuscript
*Spectral connections and equivalence conditions between noise reduction in high-dimensional PCA and delay-embedded ICA*.

Author: Ludimila Patricia da Silva de Llamas, independent researcher, Brazil.

The manuscript is in preparation for submission. This repository does not imply journal acceptance or peer-review validation.

## Scope

The work examines **conditional equivalence of reconstruction operators**, not universal identity of PCA, ICA, and SOBI. It distinguishes finite-sample NR eigenvalue correction, paired NR synthesis, component selection, and scalar FIR outputs. No EEG, patient, or measured power-system records are included.

## Installation

Python 3.12 was used for the recorded experiments. Create an environment and install:

```sh
python -m venv .venv
python -m pip install -r requirements.txt
```

Activate the environment using your operating system's standard command before installing or running the scripts. NumPy and Matplotlib versions are pinned; minor numerical differences can occur across BLAS libraries and platforms.

## Reproduce the results

```sh
python reproduce.py --experiments
python reproduce.py --figures
python verify_recorded_results.py
```

The first command reruns the numerical experiments and verifies their agreement with the reference results. The second recreates the eight English-language figures at their original dimensions and 450 dpi, with SVG and PDF versions. Outputs are written under `generated/`; reference files are never overwritten. No network connection or credentials are used by the scripts.

For a quick consistency check without rerunning Monte Carlo experiments:

```sh
python verify_recorded_results.py
```

| `verify_algebra.py` | NR floor recurrence, paired synthesis, full-subspace ICA reconstruction, prescribed-rotation counterexample | Seed 2026112303; T = 80, L = 6, K = 75, r = 3 |

## Data and interpretation

- `reference_noise_covariance.csv` contains 12 aggregated Monte Carlo rows. `reference_noise_covariance.json` also records parameters and the rewhitening example.
- `reference_sobi.csv` contains 360 record-by-method rows: 3 lengths × 40 realizations × 3 paired methods. Its JSON counterpart includes nine summaries, numerical residuals, parameters, and bound checks.
- `reference_algebra.json` records deterministic algebraic checks; its prescribed rotations are not SOBI estimates.
- `reference_geometric_illustration.json` records the separate illustrative simulations in Figure 1. These use a distinct seed and are not the main Monte Carlo experiment.
- `noise_records_T*.npz` contains the regenerated scalar white-noise records, shape `(200, T)`.
- `harmonic_records_T*.npz` contains the regenerated noiseless harmonic signal, noise, and phases, with 40 records per length. Reconstruct the observed signal as `signal + noise`.

Raw synthetic records are regenerated by the original seeded computations, without extra random draws. They are not experimental measurements. The recorded reference summaries were preserved from the manuscript calculations.

The SOBI variants use `{L,L+1}`, uncorrected `{1,2}`, and `{1,2}` corrected with the **known true noise variance**. That last variant is an oracle reference, not a blind variance estimator. Complete frequency blocks are retained. Jacobi iterations record the achieved objective; a stopping rule is not a global-optimum certificate.

### Uncertainty

In the SOBI summary table, `EP_MC` is **one** Monte Carlo standard error. Figure error bars use ±1.96 Monte Carlo standard errors. These quantify uncertainty in the estimated experimental mean, not the spread of an individual record. Matrix differences are not source-recovery or real-transient performance metrics.
